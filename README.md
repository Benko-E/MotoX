# MotoX

A browser motocross game in the spirit of Motocross Madness 1 and 2. This is
the third version: bike first this time, with simple arcade controls, built
one small step at a time.

**Play:** https://benko-e.github.io/MotoX/

## Keys

| Key | Does |
| --- | --- |
| W / S | go, brake (hold S when stopped to back up) |
| A / D | turn |
| Space | powerslide: hold it while you steer |
| C | camera: close, chase, high, helmet, free roam |
| R | back to the start |
| ` | debug menu |

## Earlier versions

- The first prototype: [Benko-E/MotoX-prototype](https://github.com/Benko-E/MotoX-prototype), playable at https://benko-e.github.io/MotoX-prototype/
- The second version: [Benko-E/MotoXv2](https://github.com/Benko-E/MotoXv2), playable at https://benko-e.github.io/MotoXv2/

## Running it

```
npm install
npm run dev
```

`npm run build` type-checks and builds the site into `docs/`, which GitHub Pages serves.
